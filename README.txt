# Ecotrace - Tracking Green Growth Through Technology

Ecotrace is a modern, responsive website designed for NGOs and environmental organizations to track tree plantation activities and measure greenery growth using satellite imagery and AI analysis.

## Project Structure
- index.html: Main landing page with hero, about, stats, and map sections.
- about.html: Detailed information about the mission and importance of tracking.
- dashboard.html: Frontend mockup of the NGO dashboard for monitoring projects.
- contact.html: Registration and contact forms for organizations.
- css/style.css: Main stylesheet containing all UI/UX designs.
- js/script.js: Main JavaScript file for animations, map, and interactivity.
- assets/: Contains images, icons, and visual assets.
- data/: Contains mock-data.json for platform statistics.

## Deployment Instructions (Hostinger)
1. Log in to your Hostinger hPanel.
2. Go to 'File Manager' for your domain.
3. Navigate to the 'public_html' folder.
4. Upload the contents of the 'Ecotrace' folder directly into 'public_html'.
5. Ensure the folder structure (css/, js/, assets/, data/) is maintained.
6. Your website will be live at your domain immediately.
